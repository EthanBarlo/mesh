# Mesh

Mesh renders React (and Vue/Svelte) components as islands inside Livewire 4 views. Livewire owns server state; Mesh carries props across the boundary and mounts the component.

## How it fits together

- **PHP component** (`App\Mesh\*`) declares props and a component **id**.
- **JS component** is a folder under `resources/js/mesh` whose `index.{tsx,jsx}` default-exports it.
- **app.ts** registers the renderers; Mesh auto-discovers every component from `resources/js/mesh`.
- **Blade** renders `<livewire:mesh :component="...">`.
- **Runtime** (`@mesh`) maps the id to a lazy chunk and mounts it.

## Minimal example

```php
// app/Mesh/Counter.php
class Counter extends \EthanBarlo\Mesh\Component
{
    public function props(): array
    {
        return ['start' => 0];
    }
}
```

```tsx
// resources/js/mesh/Counter/index.tsx
export default function Counter({ start }: { start: number }) {
  return <div>{start}</div>
}
```

```ts
// resources/js/app.ts — register renderers; components are auto-discovered
initMesh(Livewire, {
  renderers: [reactRenderer],
  debug: true,
})
```

```blade
<livewire:mesh :component="\App\Mesh\Counter::class" />
```

## Key ideas

- **Alias, not npm.** The frontend ships in the Composer package; the `@mesh` Vite alias points at it.
- **A simple id, derived identically on both sides.** PHP derives the id from the class name
  (`App\Mesh\Forms\Input` → `Forms/Input`); JS derives the same id from the folder path under
  `resources/js/mesh`.
- **Renderer from the file extension.** `tsx`/`jsx` → React, `vue` → Vue, `svelte` → Svelte.
- **Zero-config discovery.** Mesh finds every component under `resources/js/mesh` and code-splits each into its own chunk.
- **Livewire 4.** Requires `@livewireScriptConfig` and `Livewire.start()`.

## Component model at a glance

A component is a folder under the fixed `resources/js/mesh` directory containing an
`index.{tsx,jsx}` whose default export is the component. The folder name is the component id segment
and must match the StudlyCase PHP class name (case-sensitive on Linux). The path is not configurable.
